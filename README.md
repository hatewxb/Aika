# Steam Liquid Glass

Тема для клиента Steam в стиле Apple Liquid Glass. Ставится через
[Millennium](https://steambrew.app) ([документация](https://docs.steambrew.app/themes/)).

> Статус: 0.1.0 — каркас. Подключены переменные, «стеклянные» рецепты
> и анимированный фон. Разделы клиента ещё не стилизованы.

## Установка

1. Установите Millennium: https://steambrew.app
2. Подключите папку темы к Steam через junction
   (cmd **от имени администратора**):

   ```bat
   mklink /J "C:\Program Files (x86)\Steam\millennium\themes\SteamLG" "C:\Users\belok\Downloads\SteamLG"
   ```

   > Millennium ищет темы в `Steam\millennium\themes\`. В старых
   > версиях это была `Steam\steamui\skins\` — если у вас старая
   > версия, подставьте этот путь.

3. В Steam: **Steam → Настройки → Millennium → Themes** и выберите
   **Steam Liquid Glass**. Steam перезагрузит интерфейс.

## Разработка

### Запуск Steam в режиме разработчика

Полностью закройте Steam (значок в трее → «Выход»), затем:

```bat
"C:\Program Files (x86)\Steam\steam.exe" -dev
```

Удобно сделать ярлык с этой строкой в поле «Объект».
DevTools: откройте `http://localhost:8080` в Chrome и выберите нужное
окно (обычно `Steam` — это главное окно с библиотекой).

### Как применить изменения

Благодаря junction правки сразу оказываются в папке темы. Чтобы
Steam их подхватил, перезагрузите окно (F5 в окне Steam в режиме -dev)
или перевыберите тему в настройках Millennium. В крайнем случае —
перезапустите Steam.

### Структура

| Файл | Назначение |
|---|---|
| `skin.json` | Манифест темы для Millennium |
| `main.css` | Точка входа для окон клиента (только `@import`) |
| `webkit.css` | Точка входа для веб-страниц (магазин, сообщество) |
| `variables.css` | **Все** цвета, прозрачности, радиусы, blur, тени, тайминги |
| `glass.css` | Рецепты «стекла» и утилитарные классы `.lg-glass*` |
| `background.css` | Анимированный цветной фон под интерфейсом |
| `library.css` | Библиотека |
| `store.css` | Магазин |
| `friends.css` | Друзья и чат |
| `settings.css` | Окно настроек |
| `selectors.css` | Нестабильные классы Steam (вида `_3xR2b4kQ`) в одном месте |

### Правила

- Никаких «голых» значений в CSS — только `var(--lg-…)` из `variables.css`.
- Стабильные селекторы (атрибуты, структура, семантические классы) —
  в файлах разделов. Автогенерированные классы — **только** в
  `selectors.css`, с комментарием, что это и когда проверено.
  После обновления Steam чинить нужно только этот файл.
- Не вкладывайте стеклянные панели друг в друга: в Chromium вложенный
  `backdrop-filter` видит только содержимое родителя, а не весь фон.

### Настройки для пользователя

- `--lg-bg-animation: paused;` в `variables.css` — остановить анимацию фона.
  При системной настройке «уменьшить движение» анимация выключается сама.
- Цвета с пометкой `@name` в `variables.css` можно менять прямо в
  настройках темы в Millennium (поле `RootColors` в `skin.json`).
