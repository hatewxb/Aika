# Aika

Тёплая тёмная тема для клиента Steam от **hatewxb**: Fluent-структура,
панели в духе файловой системы (`library/installed.list`) и мягкие пятна
света на почти чёрном фоне. Дизайн-система — [DESIGN.md](DESIGN.md).
Ставится через [Millennium](https://steambrew.app)
([документация](https://docs.steambrew.app/themes/)).

> Статус: 0.2.0 — фундамент. Палитра, токены, шрифты (Inter, Geist Mono,
> Fraunces), многослойный фон: база, шум, сетка, три пятна света.
> Компоненты и разделы — в работе.

## Установка

1. Установите Millennium: https://steambrew.app
2. Подключите папку темы к Steam через junction
   (cmd **от имени администратора**):

   ```bat
   mklink /J "C:\Program Files (x86)\Steam\millennium\themes\Aika" "C:\Users\belok\Downloads\Aika"
   ```

   > Millennium ищет темы в `Steam\millennium\themes\`.

3. В Steam: **Steam → Настройки → Millennium → Themes** и выберите
   **Aika**. Steam перезагрузит интерфейс.

## Разработка

### Запуск Steam в режиме разработчика

Полностью закройте Steam (значок в трее → «Выход»), затем:

```bat
"C:\Program Files (x86)\Steam\steam.exe" -dev
```

Удобно сделать ярлык с этой строкой в поле «Объект».
DevTools: откройте `http://localhost:8080` в Chrome и выберите нужное
окно (обычно `Steam` — это главное окно с библиотекой).

### Если Steam закрывается сразу после «проверки обновлений»

Скорее всего, падает Millennium. Отчёты — в
`C:\Program Files (x86)\Steam\millennium\crashes\`. Быстрая проверка:
переименуйте `skin.json` в `skin.json.off` — если Steam запустился,
проблема в теме (чаще всего — нецветное значение в `root-colors.css`).

### Как применить изменения

Благодаря junction правки сразу оказываются в папке темы. Чтобы
Steam их подхватил, перезагрузите окно (F5 в окне Steam в режиме -dev)
или перевыберите тему в настройках Millennium. В крайнем случае —
перезапустите Steam.

### Структура

| Файл | Назначение |
|---|---|
| `skin.json` | Манифест темы для Millennium |
| `main.css` | Точка входа для окон клиента (только `@import`) |
| `webkit.css` | Точка входа для веб-страниц (магазин, сообщество) |
| `popup.css` | Точка входа для окон-меню (контекстные меню, выпадающие списки) |
| `root-colors.css` | Цвета для настроек Millennium (RootColors): только непрозрачные `#hex` |
| `colors.css` | Вся остальная палитра, производные акцента |
| `tokens.css` | Всё, кроме цветов: шрифты, размеры, радиусы, тени, движение, фон |
| `base.css` | `@font-face`, базовая типографика, фокус, скроллбары, reduced-motion |
| `background.css` | Фон: база, шум, сетка, три пятна света |
| `components/` | Общие компоненты: кнопки, карточки, панели, меню… |
| `sections/` | Разделы клиента: библиотека, магазин, друзья, настройки… |
| `selectors.css` | Нестабильные классы Steam (вида `_3xR2b4kQ`) в одном месте |
| `assets/fonts/` | Шрифты (только OFL) и их лицензии |
| `DESIGN.md` | Дизайн-система Aika — главный источник правды |
| `ROADMAP.md` | Что сделано и что дальше |
| `tools/` | Скрипты для разработки через CDP (не часть темы) |

### Правила

- Никаких «голых» значений в CSS — только `var(--aika-…)` из `root-colors.css` / `colors.css` / `tokens.css`.
- В `root-colors.css` — **только непрозрачные `#hex`**. Любое другое значение там роняет
  Steam при запуске, а у `rgba()` Millennium обнуляет прозрачность.
- Стабильные селекторы (атрибуты, структура, семантические классы) —
  в файлах разделов. Автогенерированные классы — **только** в
  `selectors.css`, с комментарием, что это и когда проверено.
  После обновления Steam чинить нужно только этот файл.

### Настройки для пользователя

- `--aika-motion: 0;` в `tokens.css` — остановить декоративную анимацию.
  При системной настройке «уменьшить движение» она выключается сама.
- Акцент — `--aika-accent` в `root-colors.css` (там же пресеты); свечения и рамки считаются из него в `colors.css`.
- Цвета из `root-colors.css` можно менять прямо в
  настройках темы в Millennium (поле `RootColors` в `skin.json`).
  Сохранённые там значения перебивают файл — после правок файла сбросьте их.
