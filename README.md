# Aika

**Тёплая тёмная тема для клиента Steam**

Fluent-структура · панели в духе файловой системы · мягкие пятна тёплого света на почти чёрном фоне

Автор — **hatewxb** · для [Millennium](https://steambrew.app) · версия 0.1.0a (WIP)

![Aika — страница игры в библиотеке](screenshots/library-game.png)

</div>

## О теме

Aika переодевает весь клиент Steam: библиотеку, магазин, сообщество, друзей
и чат, загрузки, настройки, меню и уведомления. Идея — спокойный тёмный
интерфейс, в котором ничего не кричит. Свет задаёт один фирменный акцент,
а фон — три медленно плавающих пятна света.

- **Тёплая палитра.** Почти чёрный фон с тёплым оттенком, акцент — мягкий
  фиолетовый. Никакого «стимовского» голубого: ссылки, кнопки, переключатели,
  прогресс, свечения и подсказки перекрашены по всему клиенту.
- **Fluent-структура.** Скругления, тонкие рамки, индикатор выбранного пункта
  в списках, понятная иерархия поверхностей.
- **Язык файловой системы.** Блоки — как панели-файлы, мелкие метки и цифры —
  моноширинным шрифтом.
- **Свет и движение.** Фон из нескольких слоёв (база, шум, сетка, пятна света),
  еле заметное свечение за курсором на крупных блоках, плавное появление
  панелей. При системной настройке «уменьшить движение» анимация выключается.
- **Статусы друзей везде одинаковые:** в игре — зелёный, в сети — акцент,
  не в сети — приглушённо. Свои значки для «отошёл» и «с телефона».
- **Тексты Steam не меняются.** Тема меняет только вид.

### Не только цвета

- **Логотип игры над трейлером** в магазине — вместо текстового названия,
  как в библиотеке.
- **Плеер трейлеров в духе Apple:** плавающая капсула с размытием, тонкая
  полоса прогресса, моноширинное время.
- **Скриншоты по играм** (профиль → «Контент» → «Скриншоты»): вместо общей
  стены — полка на каждую игру с иконкой и горизонтальной каруселью
  скруглённых скриншотов. Подгружаются по мере прокрутки.
- **Вкладки верхней панели по центру** (можно вернуть влево в настройках).

## Установка

1. Установите [Millennium](https://steambrew.app).
2. Скачайте `Aika-<версия>.zip` из [Releases](../../releases) — там только
   файлы темы, без инструментов разработки (или **Code → Download ZIP** / `git clone`).
3. Распакуйте папку **`Aika`** в
   `C:\Program Files (x86)\Steam\millennium\themes\`.
   Внутри должен сразу лежать `skin.json`:
   `…\millennium\themes\Aika\skin.json`.
4. Steam → **Millennium → Themes** → выберите **Aika**. Steam перезагрузит интерфейс.

> Тема подключает небольшие скрипты (свечение за курсором, логотип игры
> в магазине, скриншоты по играм). Если они не работают — разрешите скрипты
> тем в настройках Millennium.

## Настройки темы

Всё настраивается в Millennium → Themes → Aika (шестерёнка):

| Вкладка | Настройка | По умолчанию |
|:--|:--|:--|
| Верхняя панель | Положение вкладок «Магазин / Библиотека / Сообщество» — по центру или слева | По центру |
| Цветовые пресеты | Набор цветов: акцент и пятна света | Aika |
| Расширенное | Свои цвета — акцент, цвет наведения и три пятна света из редактора цветов темы | Выкл. |
| Расширенное | Свечение за курсором | Вкл. |
| Расширенное | Радиус свечения (ползунок, 60–400 px) | 160 px |

## Известные ограничения

- После обновлений Steam часть стилей может слететь: автогенерированные классы
  Steam собраны в одном файле (`selectors.css`), чинить нужно его.
- Иконки игр в «Скриншотах по играм» и логотипы в магазине берутся из
  открытого API [steamcmd.net](https://www.steamcmd.net) и кэшируются на 7 дней.
- У шрифта Fraunces нет кириллицы — крупные русские заголовки показываются
  запасным шрифтом.

## Для разработки

Дизайн-система — [DESIGN.md](DESIGN.md), подробный журнал работ и план —
[ROADMAP.md](ROADMAP.md).

<details>
<summary><b>Как устроена тема</b></summary>

| Файл | Назначение |
|---|---|
| `skin.json` | Манифест темы для Millennium: патчи окон, настройки темы |
| `main.css` | Точка входа для окон клиента (только `@import`) |
| `webkit.css` | Точка входа для веб-страниц (магазин, сообщество) |
| `popup.css` | Точка входа для окон-меню |
| `toast.css` | Точка входа для всплывающих уведомлений |
| `root-colors.css` | Цвета для редактора цветов Millennium: только непрозрачные `#hex` |
| `colors.css` | Вся остальная палитра, производные акцента |
| `tokens.css` | Всё, кроме цветов: шрифты, размеры, радиусы, тени, движение, фон |
| `base.css`, `background.css` | Типографика, скроллбары; многослойный фон |
| `components/` | Общие компоненты: кнопки, карточки, панели, меню, поля… |
| `sections/` | Разделы: библиотека, страница игры, магазин, сообщество, друзья… |
| `options/` | Файлы настроек темы (вкладки, пресеты, свои цвета) |
| `js/` | Скрипты: свечение за курсором, логотип в магазине, скриншоты по играм |
| `selectors.css` | Нестабильные классы Steam (вида `_3xR2b4kQ`) в одном месте |
| `assets/fonts/` | Шрифты (только OFL) и их лицензии |
| `tools/` | Скрипты для разработки через DevTools (не часть темы) |

</details>

<details>
<summary><b>Режим разработчика</b></summary>

1. Подключите папку проекта к Steam через junction (cmd **от имени администратора**):

   ```bat
   mklink /J "C:\Program Files (x86)\Steam\millennium\themes\Aika" "<путь к папке проекта>"
   ```

2. Полностью закройте Steam и запустите его с `-dev`:

   ```bat
   "C:\Program Files (x86)\Steam\steam.exe" -dev
   ```

   DevTools — `http://localhost:8080` в Chrome.
3. Правки CSS подхватываются после перезагрузки окна (F5 в режиме `-dev`)
   или перевыбора темы. Новые патчи в `skin.json` — только после перезапуска Steam.

**Если Steam закрывается сразу после «проверки обновлений»** — падает
Millennium. Отчёты — в `Steam\millennium\crashes\`. Чаще всего виноват
`root-colors.css`: там допустимы только непрозрачные `#hex`.

</details>
